# Анимист первого уровня: задания реализации L1-A

Статус: план реализации, рантайм в этой волне не менялся. Основной контракт — [plan.md §13](../plan.md).
Источник: `tools/out/items.json` (pf2e 8.6.1, 2026-10-26), полный `tools/out/html.json`, действующие каталоги и код.
Ни список `ruleKeys`, ни отсутствие записи по slug не доказывают отсутствие поддержки: проверять также `bySource` и системный эффект.
Все 14 сосудов доступны как варианты, но персонаж не получает их одновременно. Основная сущность даёт свой сосуд.

## Практики, настройка и все пять черт первого уровня

Обычная свободная классовая черта анимиста появляется со второго уровня. Практика выдаёт способность уже на первом:
литургист — Circle of Spirits, медиум — Relinquish Control, ясновидящий — Apparition Sense, шаман — Spirit Familiar.

## Обычные заклинания сущностей и дополнительные выборы

L1-A40: составить fixtures по уникальным cantrips/rank1 из таблицы сущностей и проверить текущий resolver целиком.
Уже есть правила, например, для Tangle Vine, Ill Omen, Runic Body, Rousing Splash, Caustic Blast, Sure Strike, Figment,
Puff of Poison, Charm; это не гарантия полноты всех веток. Проверить Shield, Dizzying Colors, Gouging Claw/Ignition/
Slashing Gust (в том числе persistent на крит), Hydraulic Push, Grim Tendrils, Tailwind, Protector Tree, Interposing Earth,
Déjà Vu и остальные строки. Для каждой: системное/каталог/частично/ручное решение и отдельный дефект при несоответствии.
Чисто повествовательные Prestidigitation/Message/Sigil/Telekinetic Hand/Mending не превращать в фиктивные боевые состояния;
автоматизировать подтверждённый механический остаток, если он есть. Каталог с одними заметками не считать полным покрытием.

L1-A41: обычные divine cantrips/rank1, родословные/фоновые/навыковые черты и предметы выбранных сборок — отдельная
параметризованная очередь по фактическим items. Перечень доступных вариантов не означает, что все они взяты одним героем.
Инвентаризацию выполнять на локальных fixtures/экспорте без изменения игровых персонажей и без нового build pipeline.

## Очередь, владение и проверки

1. L1-A01–A06: fixtures и аудит native/grants; самостоятельные исправления по доказанным пробелам.
2. L1-A40 и простые применения готовых эффектов — независимо от разработки Sustain.
3. После L1-C1/C3: A23/A25 как пилот повторных импульсов, затем остальные сосуды по отдельным ID A20–A33.
4. A22/A24/A30 требуют отдельной проверки реакций/перехвата, не объявляются закрытыми после одной постановки эффекта.

Исполнитель класса владеет только собственными новыми изолированными обработчиками/тестами и живым сценарием
`tests/live/level1-animist.js`. Общий lifecycle — владелец L1-C1. Врезки в существующие файлы, каталоги, источники паков,
локализацию и builtin/index принимает один интегратор по §13.5. `hold` уже в `scripts/hold.mjs`, но он не является
готовым произвольным перехватом любого урона. Новая общая схема ради одного сосуда не вводится автоматически.

Приёмка каждого ID: конкретные положительный/отрицательный сценарии строки; два автора/две цели, повтор сообщения,
смена основной сущности/источника, cast+sustain одного и разных раундов, окончание/пропуск поддержки, ресурс ровно один раз.
`node --check` затронутых `.mjs`, профильные тесты, `node --test`, валидатор правил, round-trip при изменении схемы и ru/en.
Живой сценарий — временные копии «AF тест» с уборкой. Критик проверяет смысл и дифф; без живого прогона остаётся
`implemented-needs-test`. В этой волне проверяется только документация, тесты игровых механизмов не выполнялись.
