# Наговоры-кантрипы ведьмы L1-W20…W35: разметка и первая партия

Статус: план, код не писан. Основа: `docs/level1-witch-tasks.md` (W20–W36), снимок pf2e 8.6.1 (`tools/out/items.json`), паки pf2e `spell-effects` (прочитаны копией LevelDB, RE и сроки — ниже), каталоги `rules/catalog*.json`, примитивы `scripts/rules.mjs`, счётчики механизмов `coverage.md` («Долг по механизмам», порог 30).
Названия — pf2ru; состояния оставлены слагами (`sickened`, `frightened`…), как в каталоге.

## 1. Что действует сейчас: слои и опора

- Слои: `pa → model → onhit → cat(catalog.json) → campaign`, запись ключа заменяется **целиком**. Поэтому любая правка записи из `catalog.model.json` — это копия записи в `catalog.json` с дополнением (как сделано для Липкого льда и Информационной перегрузки). `catalog.pa.json` генерируется `tools/pa-port.mjs`, руками не правится.
- Все 16 наговоров в pf2e — без собственных RE (`ruleKeys: []`), штатные эффекты лежат в паке `spell-effects` (см. таблицу). Урон кантрипа бросается штатной кнопкой карточки, в каталоге его дублировать не надо.
- Готовые поля, на которых строится партия: `challenge{byDegree, immunity}`, `apply.effect{uuid, choice, replace, unlessEffect}`, `apply.condition{policy:"max", duration{of:"origin"}}`, `sustain:true` (якорь Поддержания), `onEvent` (в т.ч. `side:"origin"`, `cost:"reaction"`, `choose`), `repeat` (повторный спасбросок на границе хода: только снимает носитель), `damage` (шаг урона), `visibility` (попарная видимость).
- Образец «минимума состояния»: Жужжащие укусы (`catalog.pa.json`, эффект `BzzBitesCritEf01` в `tools/pa-effects.authored.mjs:36`): эффект с `GrantItem` состояния `sickened` + `badge-value override 1` + `onDeleteActions: {grantee: "restrict"}`, срок `sustained`. Это и есть «минимум 1, пока заклинание активно»: второй источник состояния нельзя уменьшить, он живёт ровно столько же, сколько эффект. Нового примитива не нужно.
- Автоякорь Поддержания (`docs/plan-familiar.md`, реализован 2026-11-05) создаётся только для ведьмы с фамильяром; шаг `sustain:true` ставит якорь тому же ключу (идемпотентно), поэтому для остальных наговоров `sustain:true` ставим явно.

## 3. Рекомендованная первая партия

Порядок (от меньшего риска к большему):

1. **W35, W23, W22** — проверка того, что уже написано: `sustain:true` у условия и эффекта, конец Поддержания снимает только своё, иммунитет. Нужна не работа над каталогом, а один живой сценарий на каждого; он же подтверждает базу для следующих шагов.
2. **W31** (копия модельной записи + `sustain:true`).
3. **W24** (+ `immunity`), **W33** (`replace:true`), **W25** (`sustain:true` на эффекте быстрого лечения; приближение по степени записать в заметке записи).
4. **W21 и W26** — два эффекта пака («минимум `sickened 1`», «минимум `frightened 1`») по `BzzBitesCritEf01`; записи `catalog.json` с `sustain:true`. W26 без реакции Dismiss.

Не входит: W20, W27, W28, W29, W30, W32, W34 (ниже). Все записи — в `catalog.json` (интегратор); новые эффекты — в `tools/pa-effects.authored.mjs`, пересборка паков отдельно; 16-символьные id по образцу `BzzBitesCritEf01`.
Размер партии: 3 проверки + 4 правки S + 2 эффекта M ≈ 9 наговоров из 16. Тест: юнит валидатора записей (форма `sustain:true`+`immunity`) и один живой сценарий на группу по образцу `tests/live/level1-sustain.js`.

### 3.1. Что проверяет каждый шаг партии

- W35: сотворение при успехе/провале/крит. провале; крит. провал даёт `BzzBitesCritEf01`; конец (отмена Поддержания, срок) — иммунитет 1 мин
  и снятие минимума; повторное сотворение на цель с иммунитетом — без спасброска и урона.
- W23: провал → `stupefied 1`, крит. провал → `stupefied 2`, успех/крит. успех — ничего; Поддержание продлевает, пропуск Поддержания снимает.
- W22: выбор −5/−10 соответствует степени; эффект единственный; урон — штатной кнопкой, не записью.
- W31: эффект `TpVkVALUBrBQjULn` на цели, +2 к урону на ранге кантрипа; Поддержание; нет второго бонуса поверх RE.
- W24: цель получает `pzbU0cdyRvE66XBi`, второй раз в течение минуты — отказ (иммунитет); конец Поддержания снимает эффект.
- W33: повторное сотворение заменяет эффект и у автора, и у цели; чужие эффекты `Share Vision` не трогаются.
- W25: быстрое лечение у выбранного союзника, Поддержание; крит. успех — ничего; «0 урона от иммунитета» — отдельный ручной случай в заметке.
- W21/W26: минимум остаётся, когда `sickened`/`frightened` снижает штатный механизм; удаление только эффекта минимума (потеря видимости/слуха) оставляет само состояние.

Риски партии: (1) копии записей из `catalog.model` в `catalog.json` теряют будущие правки модельного слоя — в заметку записи указать источник;
(2) новые эффекты пака требуют пересборки паков и регистрации id в `tools/pa-effects.authored.mjs`; (3) `sustain:true` у эффекта
(не условия) работает через `applyInlineEffect` — проверить срок на карточке якоря.

### 4.1. Как считали

- Выборка: все `spell`, `feat`, `action`, `equipment`, `consumable`, `weapon`, `armor`, `shield`, `ammo`, `treasure`, `campaignFeature` из `items.json` (41 174 записи, вместе со встроенными); дубли по `uuid` схлопнуты, «уникальные имена» считаются отдельно.
- Текст: `descEn` без тегов; регулярки (без учёта регистра):
  - минимум: `can't|cannot be reduced below`; с чувством — плюс `while|as long as … see|hear` в том же предложении;
  - начало хода: `at the start|beginning of its|their|the target's turn … attempt|save` либо `save at the start|beginning of its turn`; с Sustain — те же внутри текста с `sustain`;
  - пересчёт: `retroactiv`, `bonus would turn|change|make`, `changing the outcome`;
  - против автора: `(penalty|bonus) … (attack|damage|check|save) … (against|that would harm|to harm) you|the caster`;
  - враждебное действие: `hostile act(ion)`, затем «закончит/нарушает» и «save».
- Ручная сверка списка имён (названия выше в таблице) — убрали очевидный шум; без неё цифры завышены (особенно «пары-движение»: 61 по грубой регулярке, настоящих 2).
- Цифры `coverage.md` — другой счёт (записи долга `needs-primitive` по пачкам), поэтому приведены рядом, а не вместо.
