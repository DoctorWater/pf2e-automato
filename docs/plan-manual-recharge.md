# План: ручная перезарядка (таймер ставит ведущий)

Запрос: «ведущие сами ставят таймеры перезарядки там, где она с условием или модуль её не разбирает», плюс кнопка «Перезарядка NdM» на карточке использования любой способности с перезарядкой. Правила — `CLAUDE.md` §1.1, §1.5, §2, §3.1–3.3. Реализовано; живой прогон — `tests/live/recharge-button.js`.

## 0. Решение в одной фразе
На карточке использования любой способности с перезарядкой (`isUseCard`: spell|action|feat; заклинание — только сотворение) — кнопка «Перезарядка NdM». Пока замок `rc_<id>` идёт, кнопка заблокирована; автобросок при использовании её блокирует (метка `rc_*` на карточке). Источник перезарядки: текст (авто), условный бросок из текста (по кнопке), задано в Мастерской (после использования или по кнопке).

## 1. Решения Руководителя
- «Ещё N раундов» склоняется по образцу `chat.mjs` (`PLURALS` + ключи `.one/.few/.many/.other`), без нового помощника: `builtin.limit.rcWait.*`.
- Активна только кнопка последней карточки использования предмета этим актёром (по `flags.pf2e.origin.uuid`: у несвязанных копий NPC он свой).
- В Мастерской у нераспознанных — ссылка «Добавить перезарядку» (только `isUseItem`, не у цели чужого замка), а не свёрнутая строка у всех.
- Игрок-владелец жмёт сам у своего персонажа и на своей карточке (`message.isAuthor`); остальным игрокам кнопки нет.
- «Сбросить» нет; минуты нет (замок — раунды боя); вне боя кнопка disabled, ссылка `#Recharge` живая.
- Цель чужого замка (Consume Light, перезарядку ставит Feed on Fear) своей кнопки не получает: у неё нет собственного броска. Кнопка Feed on Fear учитывает замок на всех её `ids`, в том числе Consume Light.

## 2. Данные (`scripts/mech.mjs`)
`flags.pf2e-automato.mech.recharge`: `false` — нет; `"1d4"` — авто после использования (у нераспознанного замок на самом предмете); `{on:"button", dice?}` — по кнопке, срок из текста, если `dice` нет. Старые значения валидны, миграции нет; форму строит `mechToForm`.
`rechargeSpec(item)` -> `{dice, ids, mode:"auto"|"button"} | null`: `false` -> null; объект -> по кнопке (нет срока нигде -> null); строка -> авто; флага нет: безусловный текст -> авто, условный со сроком -> по кнопке, иначе null. `rechargeEntry` (автозамок) = `rechargeSpec` при `mode:"auto"`. `rechargeFull` для условного броска отдаёт `{conditional:true, dice|null, label, cant}`; `rechargeOf`/`rechargeBase` для условного — null (автозамка у условной нет: ложный блок хуже пропуска).
`pruneMech(m, base)`: base несёт режим по умолчанию (`rc`: `auto|button|none`; `mechBase`). Срезается только значение, у которого совпали и режим, и срок; `false` срезается у нераспознанной.

## 3. Замок: один путь (`scripts/builtin/impulse-gate.mjs`)
Кнопка и автозамок пишут одно и то же: `rc_<id> = {c, until, n, dice, r, mod}` на актёре + `limitMarks` на карточке + шёпот `showRecharge`; откат при удалении карточки (`onDelete`), крит Дыхания снимает (`critClear`). Кнопка — `startRecharge(message, actor, spec)`. Следующее использование блокирует строка `recharge` в `LIMITS` по `rcLock`; Alt/`unchecked` обходят. `mode.limits=off` — кнопки нет. Предикат карточки `isUseCard` общий с `preCreate` (включая `CAST` у заклинаний).

## 4. Кнопка (`scripts/recharge-button.mjs`, `rcButtonState` в `limit-text.mjs`)
- Разметка `div.message-buttons.paf-recharge-box > button.paf-recharge[data-msg,data-ids,data-dice]`, в самом конце карточки (`chat.mjs` после блока модуля переносит её вниз). Актёр — `message.actor` по `data-msg`.
- Состояние `rcButtonState`: вне боя — disabled; карточка не из текущего боя — disabled; метка `rc_*` на карточке — disabled («брошено: до раунда N», если замок ещё идёт — «ещё N раундов»); не последняя карточка — disabled; замок по любому из `ids` — disabled (максимум по ним). Метка карточки заменяет замок актёра только в окне гонки (ключа на актёре ещё нет, карточка моложе `PENDING_MS`).
- «Последняя карточка» — один проход по сообщениям за обновление (карта `origin.uuid -> id`, кэш на такт); `ids` и срок лежат в `data-*`.
- Обновление без перерисовки: `updateCombat`, `deleteCombat`, `createCombatant`, `deleteCombatant`, `create/update/deleteChatMessage`, `updateActor` (любой `flags.pf2e-automato` в changes, в том числе удаление) и `updateToken` (`delta.flags.pf2e-automato`).
- Ссылка `#Recharge` гасится, только пока кнопка активна (или метка `rc_*` уже есть — `quenchRecharge`); переключается вместе с кнопкой.
- §3.2 «одна кнопка в один момент»: по указанию пользователя кнопка стоит всегда (disabled — не лишний шаг); отступление называем в отчёте.

## 5. Мастерская
Форма `recharge:{mode:"default"|"off"|"auto"|"button", dice}`; сегмент «Как в тексте / Нет / После использования / По кнопке» у распознанных, «Нет / После использования / По кнопке» у добавленных («Нет» убирает строку). Срок обязателен там, где из текста его нет (`workshop.mech.err.diceNeeded`). `custom` — любое значение перезарядки, включая объект с `dice`. Условная из текста — строка «по кнопке» сама. Тексты — только в существующих lang-файлах.

## 6. Риски
- Двойной путь (§3.3): пока замок идёт или карточка брошена — кнопка disabled; ссылка гасится; общий откат.
- Ложный замок: нажатие на старой карточке и вне боя запрещено; нажатие пересчитывает состояние по свежим флагам, остаточное окно гонки двух клиентов ~ один сетевой круг.
- Текст `conditional` может ошибиться (`COND_WORD`): кнопка стоит и на авто, ошибка не вредит.
