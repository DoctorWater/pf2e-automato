## 2. Plant Evidence (`feats-srd.Item.eww9tuiXPnZFZ3DU`, 1 действие, `rules: []`)

Текст: незаметно подложить цели один предмет (Bulk light/negligible), удерживаемый плутом; проверка Thievery против Perception DC цели.
Рэкет Ruffian: свободное действие при успешном Shove.

Система даёт только инлайн `@Check[thievery|defense:perception]` в карточке; RE нет. Модуль не делает ничего.

Что есть: тот же шаблон проверки против защиты уже в `catalog.campaign.json` (Shove: `onUse.check` athletics vs fortitude, опция `action:shove`,
`byDegree` с `note`). Событие `skill-check` с `action:shove` и `outcome:success|criticalSuccess` приходит владельцу (как у Mastermind с `action:recall-knowledge`).

Чего не хватает и вердикт по частям:
- Сама проверка Thievery vs Perception DC выбранной цели: **(а)**. Запись `onUse` на UUID черты: `targets:selected`, `check {statistic:thievery, vs:{defense:perception}, options:["action:plant-evidence"]}`,
  `byDegree.success` — `note` владельцу (не публикуется всем), `criticalFailure` — `note` «заметили» (решает ведущий). Без изменений кода. Объём S.
- Предложение free action после успешного Shove только при Ruffian: **(а)**, если в движке предикатов есть способ узнать рэкет владельца (проверить `events.mjs`/`predicates` на `self:` по feature/slug `ruffian`;
  при отсутствии — **(в-мини)**: добавить один предикат «у актёра есть предмет со slug X», это не новый примитив, порог ~30 документов тут не мерится: счёт по снимку — 1 документ. Тогда не делаем, а см. ниже).
  Запись на самой черте: `onEvent skill-check side:self when:[action:shove, target, outcome:success|criticalSuccess, <ruffian>]`, `apply: choose` (подтверждение, как в You're Next) + `note` «Подкиньте предмет: Thievery vs Perception DC, без траты действия».
  Бросок самой проверки остаётся в `onUse` выше. Объём S–M.
- Бремя предмета (Bulk), «удерживаемый», факт «не заметили», дальнейшие последствия (улика найдена, подбросили краденое): **(г)** — сюжетное/ручное. Решает ведущий, модуль только даёт проверку и подсказку. Секреты результатов не публикуются: исход — шёпотом владельцу и ГМу (card()).
- Если предикат Ruffian недоступен, а делать новый предикат ради одной черты нельзя (порог): оставить Ruffian-часть **(г)** — в `note` проверки «у Ruffian после успешного Shove — бесплатно», игрок жмёт сам. Это допустимый честный долг.

Вердикт: **(а)**, с условной вторичной частью. Эффекты пака не нужны. Приёмка: живой прогон «Фейя/Мерисиэль»: успех/крит успех/провал, Ruffian после Shove — подсказка один раз; не-Ruffian подсказки нет.

## 3. Trap Finder (`feats-srd.Item.oA866uVEFu1OrAX0`, `ruleKeys: [RollOption, FlatModifier]`)

Текст: +1 circumstance к Perception для поиска ловушек, КБ против ловушек и спасброскам против них (+2 при мастере Thievery); проверка на обнаружение без Search;
отключение ловушек на ранг выше.

- Бонусы +1/+2: **native** (системные RE, срабатывают по опциям ловушки). Модуль не дублирует. Вердикт **(а)-пусто** — записи в каталоге не создаём. Нужна только проверка: на актёре-плуте с чертой бросок против
  ловушки из стандартного hazard-сценария учитывает +1 (проверить `modifiers` у броска). Объём S (живой прогон, без правок).
- «Свободная» проверка без Search и ранг отключения: **(г)** — это решение ведущего/события-ловушки (скрытая информация), модуль её не публикует и не автоматизирует. Не напоминание-шёпот на каждую ловушку: правило из одних заметок — нечего автоматизировать.

Вердикт: **(г) для автоматики + проверка native**. В отчёт приёмки: «Trap Finder — системный, дополнительных правил модуля нет».

## 4. Native-стили Thief и Ruffian (часть L1-R5)

- Thief (`classfeatures.Item.wAh2riuFRzz0edPl`): системные RE, Ловкость вместо Силы в урон. **Только проверить**: smoke-тест листа (урон Ловкостью один раз, нет второго бонуса от модуля).
- Ruffian (`3KPZ7svIO6kmmEKH`, `ItemAlteration`/`ActiveEffectLike`/`CriticalSpecialization`): Sneak Attack не крупнее d8 (simple) / d6 (martial), крит-специализация при off-guard.
  **Только проверить** на двух оружиях (простое d8, простое d10, воинское d8). Модуль не дублирует. Объём S, вместе с живым прогоном Plant Evidence (тот же актёр).
- Вердикт обоих: **(а)-пусто**, проверка. Если живая проверка найдёт расхождение системы — это баг pf2e, не наш, фиксировать в долге.

## 7. Порядок работ

1. Plant Evidence: запись каталога (`onUse`) и подсказка Ruffian (при наличии предиката) — S–M. Один живой прогон на «Фейя/Мерисиэль».
2. Smoke native: Trap Finder, Thief, Ruffian — S, одним проходом по тем же героям, без правок.
3. Тесты R4 P2: Twin Feint `run()`, Surprise Attack (два NPC, Sneak Attack один раз) — M. Только тесты и живой сценарий.
4. Документация: README (Twin Feint, Tumble Behind подсказка), `level1-rogue-tasks.md` — пометить R5/R6 статус, `plan.md` §13.7 — строка о закрытии.
5. Критик перед коммитом; живая проверка вручную на вкладке ГМа (не закрывать, не двоить исполнение).

Общий объём: **M** (правка каталога — S, остальное проверки и документация).

## 8. Что остаётся ручным или долгом (с причиной)

- Результат Plant Evidence (заметили/не заметили, дальнейшая судьба предмета, Bulk) — сюжетное, решает ведущий.
- Секретное обнаружение ловушек Trap Finder и ранг отключения — скрытая информация, правило без автоматизируемой части.
- Ruffian free action Plant Evidence — только если есть готовый предикат рэкета; иначе напоминание в `note`, без нового примитива (порог ~30 документов, здесь 1).
- Avenger, Eldritch Trickster, родословные/фоновые/навыковые черты — по факту выбора героев; в партию не входят.
- Крайние случаи Surprise Attack (Delay, поздний вход), урон заклинанием по помеченному врагу Tumble Behind, NPC-копии Nimble Dodge — P2, долг.
- Без живого Foundry ни один пункт не считается принятым: до прогона статус «implemented-needs-test».

## 9. Критерий закрытия плута 1 ур.

Плут 1 уровня считается закрытым, когда: (1) Plant Evidence имеет рабочую проверку Thievery vs Perception, секреты не публикуются;
(2) Trap Finder/Thief/Ruffian проверены на герое и признаны native; (3) тесты Twin Feint `run()` и Surprise Attack добавлены и зелёные;
(4) строки L1-R5/R6 в таблицах помечены закрытыми либо «условно, вне партии» с причиной; (5) долги из §8 записаны в `plan.md` §13.7.
