# Установка

Модуль для Foundry VTT v14 (проверен на 14.370) и системы pf2e (проверен на 8.7.0).

## Как поставить

1. На экране настройки Foundry откройте вкладку «Модули», нажмите «Установить модуль» и вставьте в поле «Ссылка манифеста»:
   `https://github.com/StompingRhino/pf2e-automato/releases/latest/download/module.json`
2. Нажмите «Установить».
3. В мире включите модули PF2e AuTOMATO и socketlib.

**До первого запуска сделайте копию мира.** Версия тестовая.

## Другие модули

| Модуль | Нужен ли |
|---|---|
| socketlib | обязателен |
| libWrapper | рекомендуется |
| pf2e-toolbelt | рекомендуется |
| token-action-hud-pf2e | рекомендуется; без него в Token Action HUD нет кнопок модуля (укрытие, перезарядка) |

## Несовместим с pf2e-automations

Автоматизации pf2e-automations почти полностью (97,5%) перенесены в этот модуль, а включённые вместе модули обрабатывают предметы дважды. Отключите pf2e-automations. Если включены оба, при загрузке мира ведущий получает постоянное предупреждение.

## Работает только при ведущем в сети

Все изменения в мире делает клиент активного ведущего. Если ведущего нет в сети, автоматизации нет, а кнопки игрока предупредят об этом.

## Модуль раньше назывался pf2e-autoflow

Если вы пользовались старой версией под id `pf2e-autoflow`, данные мира нужно перенести на новый id. Это делает скрипт `tests/live/migrate-from-autoflow.js`: вставьте его в консоль ведущего (F12). Повторный запуск безопасен.
