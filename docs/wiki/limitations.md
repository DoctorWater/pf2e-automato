# Чего пока нет и известные проблемы

Покрытие в тестовой версии:

- перенос автоматизаций pf2e-automations — почти полный, 97,5%;
- в остальном компендиуме pf2e готовые правила есть у 13,6% документов, которым нужна автоматизация (2 756 из 20 206).

Если для предмета нет правила, модуль ничего не сделает сам. Правило можно дописать в [Мастерской](./workshop.md) или сообщить о нём в [Issues](https://github.com/StompingRhino/pf2e-automato/issues).

## Что ведущий заметит в игре

- **Нужен активный ведущий.** Без него автоматизации нет.
- **Несколько вкладок ведущего.** Если вы открыли мир ведущим в нескольких вкладках или браузерах, действует одна из них. В остальных автоматика только показывается.
- **Пауза.** Игрок не может поставить область из карточки, пока игра на паузе. Это поведение Foundry.
- **Правила из описания — только подсказка.** Если у предмета нет готового правила, модуль пытается угадать его по тексту описания. Угаданное ничего не делает само: ведущий жмёт «Применить (распознано)» по каждому шагу.
- **Что не распознаётся по описанию:**
  - таблицы и случайные эффекты по броску;
  - перечисления «A, B или C», где нужно выбрать;
  - состояния восприятия (скрытость, спрятан, необнаружен) простым текстом;
  - сложные сроки («пока не…», «варьируется»).
  Такие места модуль отмечает подсказкой «Не вешается автоматически», её видит только ведущий. Применяйте их вручную.
- **Не отслеживается:** распространение болезни, лечение недуга внешним эффектом (Neutralize Poison), кумулятивное снижение СЛ.
- **Проверка дальности заклинания** не работает на гексагональной сетке и без сетки, а также для заклинаний без числовой дальности и для областей.
- **Укрытие в Token Action HUD** ставится вручную, без расчёта по стенам.
- **Мастерская.** Её возможности и пределы описаны на [отдельной странице](./workshop.md).
