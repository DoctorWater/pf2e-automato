# K8. Инвентаризация сущностей кампании (мир TheGreatRoute, 34 сущности)

Проверка: `deriveFromMarkup` прогнан в node на `description` из `inventory-campaign.json` (UUID состояний -> slug по снимку `conditions.json` pf2e 8.4.1, метки — `rules/labels.json`). `node --test`: 33/33 зелёные (в т.ч. новый `tests/catalog.campaign.test.mjs`). Живой прогон в Foundry не делался.
Допущение прогона: в инвентаре нет `system.target`, поэтому ветка «заклинание с эффектом на цель» (B2) не срабатывала; в живом мире у заклинаний с `target` результат может отличаться.

Решения: ВЫВОД-H — выводится из разметки (high); КАТАЛОГ — запись в `catalog.campaign.json`; ФЛАГ — правило на предмете (slug null); PA — уже pf2e-automations; НЕТ — не автоматизируется.

## Разметка русских блоков степеней (для §7.U-18)

Встречено: `<b>Критический успех:</b>`, `<b>Успех:</b>`, `<b>Провал:</b>`, `<b>Критический провал:</b>` (блоки разделены `<br>`), и то же в `<p><strong>…:</strong> …</p>`. Двоеточие стоит внутри тега — `normLabel` его снимает, **таблицу меток менять не потребовалось**; фрагменты и неучтённые варианты записаны в `rules/labels.json` (`_seen`, `_unhandled`; парсер игнорирует ключи-массивы).
Неучтённые варианты (парсер не трогал — зона K0): блок без ссылки («аналогичен провалу, но… тошноту 2»); «как успех/как провал» не наследует ссылки; состояние вне блока («Ошеломлена 1» у Ступора); состояние агента относительно цели читается как состояние цели (п. 24); `@Check[reflex|dc:]` Сбрасывания в рус. описании потерян.
Подписи состояний в рус. тексте: «Ошеломлена 1»/«шок 1» (stunned), «тошноту 1» (sickened), «Напугано 2»/«испуг 1» (frightened), «застигнутый врасплох» (off-guard), «Скрытым»/«плохой видимости» (concealed), «спрятан» (hidden), «необнаружен» (undetected), «неуклюжесть» (clumsy), «Ничком» (prone), «заворожённость» (fascinated).

## Правила на предмете (slug null): как внедрить

Каталог не годится: у способностей нет slug и источника. Правило лежит во флаге `flags.pf2e-automato.rule` (приоритет №1). Готовые JSON — `rules/catalog.campaign.json`, ключ `flagRules` (загрузчик его игнорирует; проверены тестом). Предметы: Гипнотический приказ (Мастер ЛК), Отвести глаза (Мастер ЛК, Теневой агент), Вкрадчивое слово (Младший агент, Теневой агент), Дымовая завеса (все трое). Вручную — вкладка «Автоматизация» на предмете (вставить JSON). Скриптом из консоли ГМа (по имени; только предметы без slug и без источника; незалинкованные токены — через их актёров на сцене):

```js
const rules = (await (await fetch("modules/pf2e-automato/rules/catalog.campaign.json")).json()).flagRules;
const actors = new Set([...game.actors, ...canvas.tokens.placeables.map(t => t.actor)].filter(a => a?.type === "npc"));
let n = 0;
for (const a of actors) for (const it of a.items) {
  const r = rules[it.name];
  if (!r || it.slug || it._stats?.compendiumSource) continue;
  await it.setFlag("pf2e-automato", "rule", r); n++; console.log("rule ->", a.name, it.name);
}
console.log("готово:", n);   // откат: it.unsetFlag("pf2e-automato", "rule")
```
Без этих флагов `resolveRule` вывел бы из разметки неверные состояния у Гипнотического приказа, Отвести глаза и Вкрадчивого слова — флаги нужны как перекрытие. Скрипт не запускался (нет Foundry); предпосылка `slug:null` взята из инвентаря. Если у предмета `it.slug` в живом мире окажется непустым (pf2e выводит slug из имени), условие `it.slug` пропустит все — тогда убрать эту проверку и оставить только отсутствие `compendiumSource`.

## Где нужен макрос

Ни одного обязательного: недоступное схеме (бросок атакующего, состояния агента для цели, урон, движение) ГМ ставит вручную по заметкам блока. Кандидаты на `onUse`-макрос, если захочется: Грязный приём (Воровство против Реакции -> clumsy 1), Отвести глаза (видимость агента).

## Сомнительное / на проверку ГМу

- Сбрасывание: СЛ из статблока; Масло: применять только к существам; Дымовая завеса: срок 12 с / 2 раунда; Вкрадчивое слово: fascinated без срока; «шок» = stunned.
- Щит: иммунитет 10 минут не ставится автоматически.
- bySlug `buck`/`grease`/`battle-medicine`/`baleful-glow` — запасные ключи.
- Путь «разметка -> блок чата» живьём на 3–4 сущностях не проверялся; кандидаты: Чёрный порох (вывод high), Гипнотический приказ (флаг), Масло, Боевая медицина.
