# Перенос pf2e-automations -> pf2e-automato

Правила: `rules/catalog.campaign.json` (ключ `bySource` = UUID pf2e, `bySlug` — slug, везде однозначный в паках pf2e 8.6.1; у «Злобного взгляда пугала» источника нет — только slug). Тесты: `tests/catalog.pa-port.test.mjs`.
Сверка: тексты — англ. снимок 8.4.1; UUID эффектов/состояний дополнительно проверены по установленным пакам pf2e 8.6.1 (все существуют, тип `effect`).
Живой прогон в Foundry не делался. Что именно «ГМ вручную» — в колонке расхождений.

Общее: **как работал PA** — перехватывал бросок навыка/атаки/спасбросок по roll options (`action:trip`, `outcome:success`) и применял эффекты по исходу, брал результат из броска. **Как у нас** — правило срабатывает на использование предмета/карточки действия (`resolveRule` по источнику/slug), бросок делает модуль (`onUse.check`/`challenge`). Базовые действия, брошенные из панели «Действия» листа без предмета-карточки, правилом не охватываются (см. «Спорные места» п.1).

## Общие действия (`pf2e.actionspf2e`, `onUse.check`)

Для всех: `options:["action:<slug>"]` (чтобы работали модификаторы pf2e от черт), цель — токен в таргете. MAP (`mapIncreases`) в правилах не задан. Бросок из листа/макроса/TAH: штраф учитывает сам pf2e (игрок выбирает вариант), мы не перебрасываем. Бросок кнопкой блока с карточки предмета (атакующие манёвры — trait `attack`): модуль спрашивает у бросающего номер атаки (0/1/2 → `attackNumber`); авто-бросок NPC за ГМа — без штрафа.

Не переносилось (с причиной):
- **Stand** — у PA «снять prone»; в схеме нет шага «снять состояние».
- **Rage, Hunt Prey, Take Cover, Raise a Shield** — в pf2e 8.6.1 у действий есть `selfEffect`, систему применяет сама; PA лишь добавлял побочное (иммунитет к врем. ПЗ после Rage; метку Hunt Prey — тоже `selfEffect` с `TokenMark`). Правил не писал (конвейер модуля пропускает предметы с `selfEffect`).
- **Steady Balance** — пассив, `AdjustDegreeOfSuccess` в самом предмете.
- **Defend** (exploration) — эффект «щит поднят» есть у системы только на раунд; PA брал эффект из своего пака. Нечего применить.
- **Recall Knowledge, Seek / Hide / Sneak** — по заданию (нет состояния для применения / видимость — pf2e-vision).
- **High Jump / Long Jump / Climb** («prone при КП», общее правило PA) — броски без цели/против фиксированной СЛ, `check` требует цель.
- Хуки PA вне задачи: Rage-иммунитет на удаление эффекта, `deleteFeintEffects`/`deleteIntimidatingStrikeEffect` (кроме Устрашающего удара, у которого снятие встроено).

## Спорные места

1. **Способ срабатывания — закрыто.** Бросок действия без карточки ловится хуком `createChatMessage` по `action:<slug>` в roll options (`scripts/actions.mjs`): правило по slug из каталога, результат берётся из уже сделанного броска. Не ловятся действия, у которых pf2e не ставит `action:<slug>` (самодельные макросы).
2. **«Цель или сам кастер»** (SelfOrTargetEffect у PA): схема не имеет «если цели нет — на себя». Наставление, Умиротворение, Свет, Рунное оружие, Запрещающая защита — `selected` (на себя — таргет на себя); Вымысел, Кристалл, Брага — `self`.
3. **Степень в `ChoiceSet`-эффектах — закрыто.** `applyEffect` пишет `system.context.roll = {total, degreeOfSuccess}` из шага по степени (`ctx.degree`/`ctx.total` в `applyOps`); без итога — по-прежнему `null` (диалог ГМу).
4. **Длительность «до конца текущего хода» — закрыто.** `validateRule` принимает `value:0` только вместе с `expiry:"turn-end"`; Feint на успехе исправлен.
5. **СЛ Treat Wounds / Battle Medicine** — 15 (текст: «обычно 15»); план §1.1a в примере брал 20. Мастерская СЛ — вручную.
6. **Ссылки PA на несуществующие эффекты pf2e** (Treat Disease, Bon Mot КУ, Potency Crystal варианты): у PA они не работали; мы ссылаемся только на существующие (проверено по 8.6.1).
7. **Устрашающий удар** — единственная часть без юнит-проверки хуков Foundry (проверена только чистая `plan`): требует живой проверки: взять Муссарию (временная копия), использовать черту, затем ближний Удар по цели — при попадании и броске урона цель получает испуг 1 (крит. — 2), флаг `flags.pf2e-automato.intimidatingStrike` у актёра исчезает; промах — флаг исчезает без состояния.
8. `tests/builtin.test.mjs` (список builtin-ссылок каталога) и `tests/catalog.party.test.mjs` (счётчики: markup -> каталог, 11 -> 18) правил — иначе ломались от новых записей.
