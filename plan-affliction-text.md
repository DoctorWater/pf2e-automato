# affliction-text: долг недугов «text outside stages» (257) и «stage text» (192) — разбор и план (кода нет)

Решение: **не расширять регулярки до «чистоты», а развести два случая.** (1) Всё, что `parseStage` не разобрал только из-за формулировки, — правка разбора, без схемы (измерено +35, **сделано: каталог 266 → 297** — дефект 7 убрал 4 записи). (2) Остальное — **честный `partial`** (§0): шаги стадий (урон, состояния, штрафы) закрыты, остаток виден ГМу заметкой `def.note`; всё, что партия закрывает неверно, остаётся долгом. Новых тяжёлых примитивов в первую очередь не требуется; первым после этой работы — `linger` (отдельный план), `hold` и «срок броском» позже.

## 0. Решения пользователя (2026-10-25) — не пересматривать

1. **Partial — только честные.** Долгом остаются: (а) «состояние остаётся после срока» (linger); (б) стадии с уточнениями в остатке — `or`, `for each`, `for …ing`, `if/unless/until/as long as/instead/upon`, `for [[/gmr`; (в) случайные сроки (`/gmr`, `NdM <ед.>` в стадии); (г) записи без единой механики в стадиях («правило из одних заметок»). Остальное — partial.
2. **`def.note` — да.** Видимость — **настройкой мира**: публично (как `stage.text`) или шёпотом ГМу через `card()`; по умолчанию — публично. Место: описание носителя (`carrierSource`, `affliction-run.mjs:87`) + первая карточка стадии. **Валидатор `vAffliction` (`rules.mjs:327`) молча отбрасывает незнакомые ключи `def` — правка обязательна** (без неё заметка пропадёт без ошибки). Мастерская: поле ввода в редакторе недуга (`affliction-edit.mjs`).
3. **Смерть** — заметка ГМу «отметьте смерть», **без авто-смерти**; смертельная стадия **конечная**: у неё снимается срок стадии **и `maxDuration` недуга** (иначе `dueOf` → "end", `tickItem` удаляет носитель — «мёртвый» исчезает). Рантайм конечную стадию уже умеет (`scripts/affliction.mjs:42`: `intervalOf = secondsOf(stage.duration)`, при `duration: null` бросков нет) — правка в конвертере и тест, не в `tick`. Масштаб: **132 записи** со смертельной стадией, 110 из них в честном partial (§5); у 19 стадия несёт срок — снять.
4. **Partial-недуги — автоматически** (`confidence: model`), **но только после выборки Критика по каждой группе** (§6). Без выборки группы `--write` не запускать.
6. **Linger** — регулярку признака расширить **до выборки Критика**; лишнее уйдёт в долг, а не в partial.
7. **Записи, где вне стадий только заглушки и лор (~8) — статус «готово»**: вернуть игнор заглушек в `outsideText` и список `FLAVOR_OK` по uuid.
8. **17 заклинаний с таблицей степеней** — отдельной пачкой модели: Haiku → выборка Критика → Sonnet.
5. Технические (по рекомендации Критика): иммунитет по трейту — через `challenge.when` с `[{"not":"target:trait:…"}]` (**не** `["not", …]` — это «И» двух атомов, `predicate.mjs:9`); **юнит-тест без отдельного живого прогона**. Первым примитивом после этой работы — **`linger`**, не `hold`.

Цифры — **записи** `rules/drafts-accepted` (копии NPC = отдельные записи, `dupCount` в скобках, где важно), получены прогоном `node tools/affliction-batch.mjs` (без `--write`) и копией конвертера в scratchpad с правками (репозиторий не тронут). Деление по подгруппам — регулярки + чтение выборки (по `outsideText`/`parseStage`), границы приблизительны (± несколько записей; запись может нести несколько признаков — тогда «наличие» больше «основной»).

## 1. Исходные числа

Отчёт: `catalog 266 (копий 292); debt 527 (копий 614)`; причины: `text outside stages` **257** (копий 300, 167 имён), `stage text` **192** (копий 232, 128 имён), прочее 78 (onset 11, second save 14, no save/kind 27, npc injury 10, envenom 6, weapon 5, duration 5) — вне плана.

Состав 257: NPC-действия 187, расходники-яды 53, заклинания 17. Состав 192: действия 162, расходники 30.

**Важно: причина в отчёте — первая из цепочки.** `outsideText` проверяется раньше стадий, поэтому у 257 стадии не смотрелись. Проверка: у **184 из 257** разбор стадий тоже не чист (166 после правок §3); чистые стадии у 91 (после правок). Если одной правкой «убрать» заглушки/фразу про экспозицию, записи (проверено: −21 в «outside») **перетекают в «stage text» (+21), а не в каталог**. Две стены надо ломать вместе.

## 2. Что уже есть (проверено по коду)

- Стадия хранит `text` (≤600 знаков, `vAfflStage`), карточка показывает его (`scripts/affliction.mjs:88`). Определения недуга (`def`) полей для текста вне стадий **нет** (`vAffliction`: name, kind, save, maxDuration, onset, virulent, traits, stages).
- `stages[].mods`: `bonus` (цели — AC, спасброски, навыки, восприятие…), `speed`, `weak`, `resist`, `forbid: reactions` (`normalizeMods`). Конвертер использует из них только штрафы к AC/броскам/скорости (`ROLL_MOD`, `SPEED_MOD`).
- Условия стадии: набор frightened/sickened/drained/doomed/stunned/unconscious поднимается по максимуму и **не снимается** при смене стадии; остальные живут в обёртке (`plan-affliction.md` §4). Срок состояния отдельно от срока стадии не хранится. Срок стадии — только целое число (`vAfflDur`), броска нет.
- Испытание: `immunity {slug, duration, degrees}` (`vImmunity`, `immunityFromText`), `when` на любом шаге (предикат pf2e, `target:trait:*` доступен как roll option — `self:trait:*` у pf2e есть). `afflictionRule` **не переносит `immunity` из `base`** (собирает challenge без него).
- Прецедент частичного правила: `tools/cast-batch.mjs` (`partial: [пробелы]`, `reason: "... (partial)"`, `coverage.mjs` статус `partial` отдельной строкой). У недугов `ok`-записи пока только чистые.
- Второй барьер: `checkAffliction` проверяет и `outsideText`, и потерю урона/состояния/срока — это второй барьер для partial.

## 7. Риски

- **Partial завышает «готово»** (проект: «partial завышает готово — отдельная строка в coverage»). Меры: отдельная строка, заметка на карточке, выборка по группам, пометка «остаток ручной».
- **Правила, которые молча меняют цифры:** «нельзя снять sickened», «лечение вполовину», СЛ от типа урона. С partial игрок видит заметку, но автомат этого не делает — для групп `cant`/`while` (≈ 100 записей) это самое слабое место; смягчает видимая заметка (настройка мира) и обязательная выборка Критика по группам (решение 4).
- **Состояние без числа получает значение.** Недуги пишут `{Paralyzed} 1` (в тексте), разбор после правки положит `value` — `vAfflStage` принимает 1–10 для любого slug. **Решено в шаге А (дефект 7):** `value` только состояниям из `VALUED`; тест на Blue Dragonfly/Quoroc/Snapdrake.
- **Ложные срабатывания безымянных состояний:** слова «prone», «dazzled», «fatigued» бывают в сюжетной части («fatigued upon awakening»). Список — безопасные слова, **подтверждать выборкой** (вывод из разметки ненадёжен).
- **Две стены:** правка «outside» без правки стадий **не увеличивает каталог** (проверено), а только двигает долг; планировать вместе.
- **Дубли NPC-копий:** Graveknight's Curse — 19 копий, Filth Fever/Zombie Rot/Ghoul Whispers — по 7–10; вес записей (`dupCount`) выше, чем число имён (167/300 и 128/232). Партия-пример для Критика — самые частые.
- **`stage.text` ≤ 600 знаков:** стадии «Creeping Death»-образные упрутся в лимит; сейчас все 449 прошли валидатор, но заметка `def.note` потребует лимита и обрезки.
- **Метод:** деление регулярками + чтением, ± несколько записей; перед `--write` пересчитать на настоящем коде, не по копии.
