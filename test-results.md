Окружение: Foundry v14.366, pf2e 8.6.1, мир TheGreatRoute, клиент Gamemaster (единственный активный ГМ).
Тестовые актёры только временные: «AF Тест» (пустой character + черта «Проворное уклонение» `nimble-dodge` из feats-srd),
«Гоблин-поджигатель» и два «Гоблин-боец» из pf2e.pathfinder-monster-core. Персонажей игроков не трогали.
Сценарий (`af-harness.js`): временная сцена 20×15; «AF Тест» получает из equipment-srd «Дымовая шашка (малая)» и «Бравая брага (малая)».
1. `smoke.toMessage()` → регион-круг r=150px над двумя бойцами с флагами как у системы:
   `flags.pf2e = {areaShape:"burst", messageId, origin: item.getOriginData()}`; через 3.5с — поведения/состояния;
   боец 1 уходит из зоны; затем регион удаляется.
2. `breatheFire.toMessage()` → регион-конус над двумя бойцами с `flags.pf2e.messageId` сообщения заклинания.
3. `brew.consume()`.
4. Боец 1 атакует «AF Тест» (strike.variants[0].roll с shift-событием, цель через `canvas.tokens.setTargets`).
5. Нажаты все кнопки в карточках модуля (кроме отмены).

## Факты API, установленные вживую
- `item.getOriginData()` в pf2e 8.6.1 = `{uuid, type, rollOptions}`; **поля `slug` нет**, slug только в rollOptions
  (`origin:item:slug:smoke-ball-lesser`). Регион, созданный кнопкой шаблона, несёт его в `flags.pf2e.origin`.
- Модульные подтипы RegionBehavior регистрируются нормально: `module.json documentTypes.RegionBehavior.zone` +
  `CONFIG.RegionBehavior.dataModels["<id>.zone"]` → тип виден, поведение создаётся.
- Диспетчеризация событий v14: `RegionDocument#_handleEvent` → `RegionBehavior#_handleRegionEvent` → статические
  `constructor.events[name]` И (если `system.events.has(name)`) `system._handleRegionEvent`. Ошибки обработчиков — только в console.error.
- `actor.increaseCondition("concealed")` на NPC работает, возвращает ConditionPF2e.
- `game.time.worldTime` в мире отрицательный (-10273560; Simple Calendar) — логика сроков на `> 0` ломается.
- Броски удара игнорируют `skipDialog:true`; пропуск диалога — событие с shiftKey (eventToRollParams).
- `game.user.updateTokenTargets` в v14 нет; есть `canvas.tokens.setTargets(ids)`.
- **Без модуля** pf2e уже сам вешает эффект «Бравой браги» при расходе (`effect-bravos-brew`) → тест 3 закрыт системой,
  модуль не должен дублировать.
- Ошибки `TokenMagic is not defined` (sequencer) — от анимаций Automated Animations, ссылающихся на Token Magic FX, не от прототипов.
- В мире активны pf2e-toolbelt (Template Helper после создания региона кнопкой: «Remove Template» включён по умолчанию —
  удаляет регион и на Target, и на Cancel), pf2e-automations, xdy-workbench, pf2e-vision (свой модуль: направленная видимость в бою).
